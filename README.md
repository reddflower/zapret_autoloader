# zapret_autoloader [ru]

> [!IMPORTANT]
> Autoloader — это неофициальное дополнение (не форк) для Zapret'а от Flowseal. https://github.com/Flowseal/zapret-discord-youtube

> [!WARNING]
> Поместите Autoloader в папку с Zapret, затем отдельно запустите Autoloader и установите, выбрав функцию `Install AutoLoader`.
> Autoloader изменит код Zapret, после чего Zapret будет автоматически добавлять нерабочие сайты которые вы посещаете в свои списки, от чего они снова начнут работать. (через время)
>
> (На самом деле Autoloader меняет несколько строк в Zapret: "--hostlist" на "--hostlist-auto"; если вы разберётесь, как это работает, то сможете сделать всё самостоятельно.)

> [!CAUTION]
> # ВАЖНО
> Не запускайте AutoLoader через функцию Zapret'a `Install service`.
> В таком случае у вас перестанет работать Zapret.
> Чтобы починить Zapret, просто не выбирайте AutoLoader как один из General'ов, просто выберете другой

# zapret_autoloader [eng]

> [!IMPORTANT]
> Autoloader is an unofficial add‑on (not a fork) for Zapret by Flowseal. https://github.com/Flowseal/zapret-discord-youtube

> [!WARNING]
> Place Autoloader in the folder with Zapret, then run Autoloader separately and install it by selecting the `Install AutoLoader` function.
> Autoloader will modify Zapret’s code, after which Zapret will automatically add the non‑working websites you visit to its lists, causing them to start working again. (after some time)
>
> (In fact, Autoloader changes a few lines in Zapret: "--hostlist" to "--hostlist-auto"; if you figure out how it works, you’ll be able to do everything yourself.)

> [!CAUTION]
> # IMPORTANT
> Do not run AutoLoader via Zapret’s `Install service` function.
> In this case, Zapret will stop working.
> To fix Zapret, simply don’t select AutoLoader as one of the General options — just choose something else.
