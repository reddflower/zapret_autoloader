# zapret_autoloader 

> [!IMPORTANT]
> Autoloader — это неофициальное дополнение (не форк) для Zapret'а от Flowseal. https://github.com/Flowseal/zapret-discord-youtube
> Поддерживается для версий Zapret'a - `1.9.7` и выше

> [!TIP]
> Поместите Autoloader в папку с Zapret, затем отдельно запустите Autoloader и установите, выбрав функцию `Install AutoLoader`.
> Autoloader изменит код Zapret, после чего Zapret будет автоматически добавлять нерабочие сайты которые вы посещаете в свои списки, от чего они снова начнут работать. (через время)
>
> (На самом деле Autoloader меняет несколько строк в Zapret: "--hostlist" на "--hostlist-auto"; если вы разберётесь, как это работает, то сможете сделать всё самостоятельно.)

> [!CAUTION]
> # ВАЖНО
> Не запускайте AutoLoader через функцию Zapret'a `Install service`.
> В таком случае у вас перестанет работать Zapret.
> Чтобы починить Zapret, просто не выбирайте AutoLoader как один из General'ов, просто выберете другой 
> 
> После первого запуска Autoloader пропадёт из списков Zapret'а
